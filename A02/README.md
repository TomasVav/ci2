

\# A02 - Text File Analysis



This project contains a Python script for text file analysis.

It implements assignment 2.



\## Requirements



\- Python 3



No additional libraries are required.



\## Installation



Clone the repository from GitHub:



```bash

git clone https://github.com/TomasVav/ci2.git

```



Navigate to the assignment directory:



```bash

cd ci2/A02

```



\## Usage



Run the script with the provided test file:



```bash

py texter.py test.txt

```



Alternatively, use:



```bash

python texter.py test.txt

```



To display help:



```bash

py texter.py --help

```



\## Functionality



The script performs two operations:



1\. Counts the total number of lines in the text file.

2\. Counts lines containing the word "sed" (case-insensitive).



Each matching line is counted only once.



\## Test Results



Input file: test.txt



Output:



```text

Total number of lines: 27

Lines containing 'sed': 9

```
